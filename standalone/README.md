# C-CORE スタンドアロン版 — タスク管理 & 企業情報

## 概要

C-CORE システムから「**タスク管理**」と「**企業情報**」機能のみを切り出した軽量スタンドアロンアプリです。
同じ Genspark 上でホスティングされるため、テーブルAPIを共有利用できます。

---

## ファイル構成

```
standalone/
├── index.html          メインページ（タスク管理 / 企業情報）
├── login.html          ログインページ
├── js/
│   └── app.js          スタンドアロン用JavaScript（C-COREから機能抽出）
└── css/
    └── style.css       スタイルシート（C-COREと同一デザイン）
```

---

## 使用するテーブル

| テーブル名        | 用途                           |
|-------------------|-------------------------------|
| `tasks`           | タスクデータ                   |
| `accounts`        | スタッフ（アカウント）情報     |
| `daily_work_logs` | 日次稼働ログ                   |
| `schedules`       | スケジュール（読み取りのみ）   |
| `company_info`    | 企業情報・パスワード           |
| `quick_links`     | クイックリンクバー             |
| `announcements`   | インフォメーション             |
| `shop_info`       | 新店情報                       |

---

## セッション管理

- セッションキー: `ccore_task_session`
- 保存場所: `sessionStorage`
- 値: `'ok'`（ログイン成功時にセット）
- ログインパスワード: `company_info` テーブルの `login_password` または `master_password` フィールド

---

## 機能一覧

### ✅ タスク管理ページ
- スタッフタブ切り替え（ダッシュボード / 個人ページ）
- ダッシュボード：今日の稼働時間・スタッフ概要テーブル・期限超過タスク
- スタッフ個別ページ：タスク一覧・進捗切り替え・今日フラグ・時間入力
- タスク追加 / 編集 / 削除モーダル
- クイックリンクバー（管理モーダル含む）
- インフォメーション（タイトル / 期間 / URL の行管理）
- 新店情報（店舗名 / 工事期間 / オープン日 / 受付 / スポンサー）
- 完了タスクの1週間後自動削除

### ✅ 企業情報ページ
- 基本情報（会社名・住所・電話・メール・代表者など）
- 口座情報（銀行・支店・口座番号）
- インボイス（適格請求書番号・備考）
- 利益率アラート設定
- 決算期設定
- ロゴ画像アップロード（自動リサイズ・200KB以下圧縮）
- パスワード管理（マスター / ログインPW の表示・編集）

### ✅ アカウント管理（企業情報ページ内）
- スタッフ登録 / 編集 / 削除
- 想定実動時間・ポジション・管轄タグの設定

### ✅ DBバックアップ
- サイドバーの「DBバックアップ」ボタンからJSON形式でダウンロード
- 対象テーブル: tasks / accounts / company_info / quick_links / announcements / shop_info / daily_work_logs

---

## ログイン方法

1. `login.html` にアクセス
2. C-COREの企業情報で設定したパスワードを入力
3. ログイン後、`index.html`（タスク管理）に遷移

> **注意**: `company_info` テーブルが空の場合、初回ログイン時に自動的にデフォルトレコードが作成されます（パスワード: `Collection0704`）。ログイン後、企業情報ページで変更してください。

### テーブルの共有
スタンドアロン版はC-COREメインシステムと**同じテーブルを共有**します。
- タスクデータは両システムで同期して確認・編集可能
- 企業情報も共有（どちらで変更しても反映される）
